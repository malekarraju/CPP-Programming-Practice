# C++ Programming Practice

A structured collection of C++ programs and practice exercises developed to strengthen my understanding of C++ programming, Object-Oriented Programming, and problem-solving.

This repository documents my learning journey from C++ fundamentals to core OOP concepts through hands-on implementation.

## 📚 Topics Covered

### 1. C++ Basics

Fundamental C++ programming concepts including:

- Variables and Data Types
- Input and Output
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Basic Programming Problems

### 2. Object-Oriented Programming

The `OOPs` section covers the major concepts of Object-Oriented Programming:

```text
OOPs/
│
├── 01-Class-and-Object/
├── 02-Constructor/
├── 03-Encapsulation/
├── 04-Inheritance/
├── 05-Polymorphism/
├── 06-Abstraction/
└── 07-Exception-Handling/
```

#### Class & Object
Understanding classes, objects, data members, and member functions.

#### Constructor
Programs demonstrating constructors and object initialization.

#### Encapsulation
Understanding data hiding and controlled access to class members.

#### Inheritance
Implementation of different inheritance concepts in C++.

#### Polymorphism
Programs covering compile-time and run-time polymorphism.

#### Abstraction
Understanding abstraction and implementation through classes and interfaces.

#### Exception Handling
Programs demonstrating error and exception handling using:

- `try`
- `catch`
- `throw`

### 3. Function Overloading

Programs demonstrating function overloading and compile-time polymorphism.

Example:

```cpp
int add(int a, int b);
float add(float a, float b);
```
